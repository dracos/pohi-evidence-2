T have been employed by Fujitsu Services, for 6 years and 7 months as Audit Manager for Post
Office Account. I have working knowledge of the computer system known as Horizon, which is a
computerised accounting system used by Post Office Ltd and I am authorised by Fujitsu Services

to obtain information regarding system transaction information processed on the Horizon system.

I have been asked to explain the audit archive system used by Horizon and the process for
deleting data from the system. I have also been asked to refer to specific requests for archived

data relating to a number of Post Office outlets.

When audit data is written to the archive it has a deletion date associated with it. This deletion
date is derived from a data retention period specified in the contract with Post Office Ltd. Similar
types of data files are collected into ‘Savesets’ prior to being written to tape, ‘Saveset’ being the
term used by the Legato archiving software to describe this collection. Each ‘Saveset’ has a
deletion date associated with it equal to the last data file to be collected in it. ‘Savesets’ are
written to the Digital Linear Tape (DLT) until such time as the tape is full, at which point a new
tape is loaded. Legato maintains a database of data files, ‘Savesets’ and DLT numbers such that it

is able to track a single data file to the DLT to which it has been written.

Once a Saveset’s specified deletion date has been reached it is marked by Legato as ‘Recyclable’.
At this point the data files in the Saveset are inaccessible. Once all Savesets on a DLT have been
marked as ‘Recyclable’ the DLT is itself marked by Legato as available for re-use. All elements

of this process are automated.
