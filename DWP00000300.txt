Live Trial Risk Assessment
( see attached copy of the Live Trail Risk Assessment document - copy fox non attendees }

Forum members were taken through the risk assessment matrix for Live Trial by Carol
Jepmond. The matrix was divided into 4 headings. Contractual, Delay, Disruption and
Instability and also Data Validity.

The assessment indicates whether the risk is:

High The decision is unacceptable for BA

Medium BA can potentially live with the risk, however, it will result in a need to
change the decision making process.

Low BA consider this an acceptable risk.

This document provides initial thoughts regarding the risks presented by Live Trial. It is
recognised that the document does not allot responsibility for any action taken, however,
this will be done when the risks and action have been agreed.

1.1 Contract with Pathway not signed. If the Pathway contract is not baselined then

1.2 Single stage Acceptance process not
supported by BA approach.

The initial Pathway contract worked on the
assumption that there would only be a need
for one Live Trial, however, following a
change to the plan we have decoupled ChB
and Multi Benefits. BA are, therefore looking
for some sort of acceptance for each of these
stages as well as for NR2.

1.3 Exit process for Live Trial unclear. The exit process describes the process by
which we agree when Live Trial has finished
and when we are ready to move onto the next

stage.

1.4 Sponsors unable to agree on acceptance
criteria results,

This concerns the eventuality that BA and
POCL disagree over findings during Live
Trial.

2.1 Completion of migration of existing 202
Post Offices delayed.

The migration is due to be finished 5/4/99. If
the migration is delayed for any reason it
would result in the delay of the Data Centre
migration. POCL and Pathway have indicated,
however, that if the POs did not fully migrate
we could still continue with the Data Centre
migration and pay customers clerically.

2.2 Data Centre migration delay.

Migration is scheduled for 8/9th May. 15/16th
May can only be used if absolutely necessary
as those 2 days are scheduled for the Yr 2000
power down. The 12/13th June is scheduled
as the next available contingency weekend.

It is unclear what slippage will result if the
15/16th May weekend is used.

2.3 Rollout of additional POs delayed.

The additional 104 POs will rollout from 17th
May for 3 weeks. There is an expected lag of
4 weeks for existing customers coming
through the system, Any delay in this rollout
would add to the lag time.

3.1 Products unstable at the start of Live Trial.

Unstable products would result in evaluation
problems.

3.2 Inability to stabilise after 1c migration.

There is some concern over the impact on
evaluation of POs were unable to stabilise
following the Data Centre migration.

3.3 Changes to products introduced during
Live Trial.

Items on the KPR which result in introducing
system fixes would then require changes to
products. This may result in the change in the
evaluation basis.
